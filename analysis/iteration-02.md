# 第二轮：紧凑布局与左侧分组列表

日期：2026-11-11（Asia/Shanghai）。运行时及当前生成安装包版本：0.3.1。侧栏已安装的 0.2.0 启动包装通过本地开发更新加载本轮代码，无需用户重复安装。

## 用户反馈与本轮范围

- 移除顶部大段空白和无用区域。
- 横向 Tab 体验不佳，尝试其他交互形式。
- 本轮采用左侧常驻分组列表作为可体验的候选方案；是否符合使用习惯，仍等待用户反馈。

## 已实现

- 收起原用户名、会员和下载提示组成的整块书架头部，改用右侧紧凑的当前分组标题与已显示书籍数量。
- 左侧显示现有 21 个分组，支持文字筛选；分组列表独立纵向滚动，“未分组”固定在滚动列表顶部。
- 筛选无结果时显示提示，并保留“未分组”入口。
- 右侧使用自适应书籍网格，去除原有卡片大间距和占位元素。
- 在约 1043 像素的验证视口下仍保留五列书籍。书籍首排从 y≈294 上移到 y=144，减少约 150 像素的顶部占用。
- 分组读取、书籍归属和原站继续加载逻辑沿用上一轮；未增加书架写入行为。

## 验证

- 运行时版本通过开发更新自动到达侧栏。
- 筛选“设计”只保留“未分组”“设计”“游戏设计”三个导航入口。
- 点击“游戏设计”后，地址、当前分组高亮、右侧标题和书籍内容一致。
- 筛选不存在的名称时出现空结果提示，书籍卡片数量保持不变。
- 清除筛选、返回未分组、刷新后，索引加载完成仍显示完整的 22 个导航入口。
- 左侧列表实际滚动 319 像素后，“未分组”的上边缘仍与列表上边缘一致，确认固定入口生效。
- 主页面没有横向溢出。
- 源码及生成用户脚本通过 Node.js 语法检查。
- 当前首屏截图保存为 `analysis/shelf-sidebar-preview.jpg`，保留了截图时用户正在浏览的“创业手边书”分组。

注意：页面刷新后索引是异步加载的，不能只等待 style 标签出现就判断布局完成。本轮检查等待 `data-wr-rea-status=active` 后再评估导航和布局。
